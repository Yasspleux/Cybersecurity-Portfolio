# Security Risk Assessment

## 📝 Scenario Overview
As a security analyst for a social media organization, I was assigned to address a major data breach that compromised the personal information (names and addresses) of the company's customers. The goal of this project is to implement strong, consistent network hardening practices to prevent future attacks and data breaches.

## ⚠️ Identified Vulnerabilities
During the network inspection, four critical vulnerabilities were discovered that put the organization at immediate risk:
1. **Access Control:** Employees actively share passwords.
2. **Authentication:** The database administrator password is set to the default credentials.
3. **Network Security:** Firewalls lack proper rules to filter incoming and outgoing traffic.
4. **Identity Protection:** Multifactor Authentication (MFA) is not implemented across the organization.

## 🎯 Project Objective
The objective of this activity is to perform a comprehensive **Security Risk Assessment**. This document analyzes the recent security incident, evaluates the risks associated with the discovered vulnerabilities, and provides actionable recommendations and methods to harden the network architecture and secure the infrastructure against future threats.
